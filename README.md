# 📚 Application de Gestion d'une Bibliothèque

Une application web complète permettant la gestion d'une bibliothèque, incluant la gestion des livres, des emprunts, des utilisateurs et des retours.

## 🚀 Fonctionnalités

- 🔍 Rechercher, ajouter, modifier et supprimer des livres.
- 👤 Gestion des utilisateurs (emprunteurs, bibliothécaires, etc.).
- 📅 Suivi des emprunts et des retours de livres.
- 📊 Tableau de bord pour la supervision générale.
- 🔐 Authentification sécurisée.

## 🛠️ Technologies utilisées

- **Back-end** : Laravel (PHP Framework)
- **Base de données** : MySQL
- **Front-end** : HTML, CSS, JavaScript, Bootstrap
